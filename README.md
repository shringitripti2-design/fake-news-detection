# FAKE NEWS DETECTION – A MACHINE LEARNING BASED SYSTEM

A complete college project for detecting fake news articles using Machine Learning (Logistic Regression), Natural Language Processing (NLTK), TF-IDF Feature Extraction, and a web application interface built with Streamlit.

---

## 📌 Project Overview
With the exponential growth of digital media and social networks, misinformation and fake news spread rapidly, influencing public opinion, financial markets, and democratic processes. This project presents an automated **Machine Learning-based Fake News Detection System** that analyzes the textual content of any given news article and predicts whether it is **REAL** or **FAKE** along with a confidence percentage.

---

## 🛠️ Technologies Used
- **Programming Language:** Python 3
- **Machine Learning:** Scikit-learn (Logistic Regression, Train-Test Split, Evaluation Metrics)
- **Natural Language Processing (NLP):** NLTK (Stopwords removal, Porter Stemming, Tokenization, Regex)
- **Data Handling:** Pandas, NumPy
- **Feature Extraction:** TF-IDF (Term Frequency-Inverse Document Frequency)
- **Visualization:** Matplotlib, Seaborn
- **Model Persistence:** Joblib
- **Web Interface:** Streamlit
- **Dataset Source:** Kaggle Fake News Dataset


## 📊 Model Evaluation Metrics
The model is evaluated on unseen test data using standard classification metrics:
- **Accuracy:** Overall percentage of correct predictions.
- **Precision:** Ratio of true positive fake predictions to total predicted fake.
- **Recall:** Ratio of true positive fake predictions to actual fake articles.
- **F1-Score:** Harmonic mean of precision and recall.
- **Confusion Matrix:** True Positives, True Negatives, False Positives, False Negatives.

## 🎓 College Viva & Interview Q&A

**Q1: Why did you choose Logistic Regression for Fake News Detection?**
> **Answer:** Logistic Regression is a highly effective, interpretable, and computationally efficient linear classifier for high-dimensional sparse text data generated by TF-IDF vectorization. It provides calibrated probability scores (confidence percentage).

**Q2: What is TF-IDF and why is it used?**
> **Answer:** TF-IDF stands for Term Frequency-Inverse Document Frequency. It evaluates how important a word is to a document relative to the whole corpus. It penalizes frequent common words while giving higher weight to informative keywords.

**Q3: What preprocessing steps were applied?**
> **Answer:** We used NLTK to perform case folding (lowercasing), remove URLs, HTML tags, punctuation and numbers, remove English stopwords, and apply Porter Stemming to reduce words to their base root form.

**Q4: How do you prevent overfitting?**
> **Answer:** We split the data into 80% training and 20% testing sets using stratified splitting, applied L2 regularization in Logistic Regression, and limited maximum TF-IDF features to 5,000.
